# ADR-005：本地文件存储与去重

## 状态

Accepted

## 决策背景

第一阶段需要保存上传原件并为后续对象存储扩展留出边界。当前代码没有文件上传或文件存储实现。

## 决策内容

- 第一版使用本地文件系统。
- 通过文件存储接口抽象，预留 MinIO/S3 等扩展能力。
- 使用逻辑删除和异步物理清理。
- 使用 SHA-256 实现租户内文件去重。
- 第一版支持 PDF、DOCX、TXT、Markdown。
- 业务 API 不暴露本地物理路径。

## 备选方案

- 首版直接绑定某云对象存储：本轮未选定。
- 向业务 API 返回物理路径：会暴露部署内部路径且耦合存储实现。

## 决策理由

**分析补充：** 文件存储接口可隔离物理后端；租户内 hash 可识别同租户相同内容，不应推导为跨租户去重。

## 影响及约束

业务资源 Document 与物理文件对象是不同概念；逻辑删除后仍需满足异步清理。路径必须由服务端存储适配器解析，访问原件需经过授权 API。
