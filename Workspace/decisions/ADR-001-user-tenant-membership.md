# ADR-001：用户与租户成员关系

## 状态

Accepted

## 决策背景

系统需要以租户作为业务数据隔离边界，并支持用户在不同租户中拥有不同成员身份。当前实现尚无 User/Tenant 持久化代码。

## 决策内容

- 使用全局 `User`。
- 使用 `TenantMember` 表示 User 与 Tenant 的成员关系。
- 一个用户可以加入多个租户。
- `TenantMember` 至少承担 `user_id`、`tenant_id`、`role`、`status` 等成员属性。
- `(user_id, tenant_id)` 唯一。
- 租户角色属于成员关系，不属于全局 User。

## 备选方案

- User 直接含单一 tenant_id：不满足用户加入多个租户。
- 每租户复制 User：身份和凭证难以全局管理。

## 决策理由

**分析补充：** 成员关系实体可表达同一全局身份在不同租户中的独立角色和状态。

## 影响及约束

登录主体需解析当前租户成员关系；授权须检查成员状态。字段类型、主键策略和索引属于数据库设计阶段，尚未批准。本 ADR 不表示相关表已创建。
